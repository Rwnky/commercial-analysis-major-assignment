# 数据来源合规声明

- **数据源名称**：Brazilian E-Commerce Public Dataset by Olist
- **数据源 URL**：https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- **获取方式**：Kaggle 官网 ZIP 手动下载（白名单方式，非爬虫）
- **获取日期**：2026-10-31
- **授权/License**：CC BY-NC-SA 4.0
- **数据规模**：orders 主表 99441 条，清洗后有效已送达订单 96478 条。宽表记录数满足 ≥500 条要求。
- **抽样说明**：本项目使用全量数据进行建模分析，未进行抽样。
- **非爬虫声明**：未使用 Scrapy、Selenium、requests 网页解析等网页抓取方式。
- **使用限制**：仅用于嘉兴大学《商业数据分析》课程期末大作业学习与研究。
